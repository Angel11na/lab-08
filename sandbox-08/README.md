# Лабораторна робота №8 — Пісочниця «Дайте їй мову»

## Структура проєкту

- `sandbox-08/` — директорія з розв'язками практичних завдань.
- `sandbox-08/task1.cpp` — лічильник слів.
- `sandbox-08/task2.cpp` — калькулятор на один рядок.
- `sandbox-08/task3.cpp` — перевірка та перетворення шістнадцяткових чисел.
- `sandbox-08/task4.cpp` — однозв'язний список.
- `sandbox-08/task5.cpp` — перевірка контрольної суми GPS.
- `sandbox-08/task6.cpp` — виправлення помилок у фрагментах коду.


---

## Завдання 1. Лічильник слів

**Файл:** [task1.cpp](sandbox-08/task1.cpp)

Реалізовано лічильник слів у рядку. Роздільниками слів є пробіл, кома та символ табуляції `'\t'`.

Для визначення початку нового слова використовується логічна змінна `inside`, яка показує, чи перебуває програма всередині слова.

### Перевірка

```g++ task1.cpp -o task1 && ./task1
```

**Очікуваний результат:**

```text
3 2
```

---

## Завдання 2. Калькулятор на один рядок

**Файл:** [task2.cpp](sandbox-08/task2.cpp)

Реалізовано простий калькулятор, який аналізує арифметичний вираз, що складається з двох цілих чисел та оператора.

Підтримуються операції додавання, віднімання та множення. Додатково реалізовано перевірку правильності виразу: після другого числа не повинно залишатися зайвих символів.

Якщо виявлено зайвий символ, програма виводить його позицію у форматі `error at N`.

### Перевірка

```g++ task2.cpp -o task2 && ./task2
```

**Очікуваний результат:**

```text
46
error at 3
```

## Завдання 3. Правильне шістнадцяткове число

**Файл:** [task3.cpp](sandbox-08/task3.cpp)

Реалізовано перевірку та перетворення шістнадцяткових чисел.

Функція `hex_value()` проходить рядок посимвольно. Для кожної цифри попередній результат множиться на 16, після чого додається значення поточної цифри.

Таким чином реалізовано перетворення шістнадцяткового числа у десяткове.

### Перевірка

```g++ task3.cpp -o task3 && ./task3
```

**Очікуваний результат:**

```text
65 255 418
```

---

## Завдання 4. Однозв'язний список

**Файл:** [task4.cpp](sandbox-08/task4.cpp)

Реалізовано однозв'язний список, у якому кожен вузол містить значення та вказівник на наступний вузол.

На відміну від додавання на початок списку, нові елементи додаються в кінець за допомогою вказівника `tail`.

Програма виводить усі елементи списку, визначає його довжину та звільняє виділену динамічну пам'ять за допомогою `delete`.

### Перевірка

```g++ task4.cpp -o task4 && ./task4
```

**Очікуваний результат:**

```text
1 2 3
3
```

---

## Завдання 5. Контрольна сума GPS

**Файл:** [task5.cpp](sandbox-08/task5.cpp)

Реалізовано перевірку контрольної суми GPS-повідомлення у форматі NMEA.

Функція `check_nmea()` обчислює контрольну суму за допомогою операції XOR (`^`) над символами між `$` та `*`.

Отримане значення порівнюється з двома шістнадцятковими цифрами, записаними після символу `*`.

### Перевірка

```g++ task5.cpp -o task5 && ./task5
```

**Очікуваний результат:**

```text
1 0
```

`1` означає, що контрольна сума правильна, `0` — що повідомлення було змінене.

## Завдання 6. Токени руками

**Файл:** [task6.cpp](sandbox-08/task6.cpp)

Реалізовано невеликий лексичний аналізатор, який розпізнає три типи елементів: ідентифікатори, числа та знаки пунктуації.

Виправлено обробку ідентифікаторів: тепер програма зчитує всі послідовні літери, а не лише одну.

Також перевірено та виправлено шість проблемних фрагментів коду, пов'язаних із синтаксичними помилками, неініціалізованими змінними, переповненням, виходом за межі масиву, перетворенням типів та порівнянням чисел із плаваючою крапкою.

### Перевірка

```g++ task6.cpp -o task6 && ./task6
```

**Очікуваний результат:**

```text
5
0
2147483648
3
300
equal
```

## Висновок

Під час виконання лабораторної роботи було розглянуто основні принципи обробки тексту та організації даних у C++. Реалізовано сканування рядків, розбір арифметичних виразів, перевірку числових значень, роботу з динамічною пам'яттю та однозв'язними списками, обчислення контрольних сум і лексичний аналіз.

Практична робота допомогла закріпити використання циклів, умов, функцій, вказівників, динамічного виділення пам'яті та побітових операцій, а також навчитися виявляти й виправляти типові помилки програмування.
